# 智能数字 PID 控制器设计方法研究

本科毕业设计配套代码。研究用神经网络辅助数字 PID 的参数生成：在单输入单输出对象上验证 BP 神经网络在线生成 PID 参数，在多变量航空发动机对象上验证「稳态前馈 + 直接通道解耦 + BP 增量式比例-积分增益 + RBF 离线雅可比」的控制器结构，并与同口径整定的固定参数 PID 对比。

## 目录结构

```
src/
  siso_bp_pid/     单对象侧：被控对象、BP 预训练、RBF 辨识、固定 PID 整定、测试台
  mimo_engine/     发动机侧：BP/RBF 离线预训练、验证选模、测试、结果绘图
  tools/           绘图脚本
results/
  siso/            单对象侧的图、指标表与绘图数据
  mimo/            发动机侧的图与绘图数据
docs/              实验设置与结果口径说明
archive/           历史探索版本（Simulink 原型、工具配置），非最终成果
```

## 运行环境

- MATLAB：脚本使用 `readmatrix`、`interp2`、`load`/`save` 等函数；无 Simulink 模型依赖（历史 Simulink 原型在 `archive/`）
- Python 3：绘图脚本依赖 `numpy`、`matplotlib`
- 脚本按当前工作目录读写 `*.mat`，运行前请先 `cd` 到对应源码目录

## 主要结果与口径

以下数字均来自仿真，引用时请连同限定条件一起使用。

**单对象（一阶非线性时变）**：六类工况综合误差平方积分 0.094830，同口径整定的固定参数 PID 为 0.097446，降低约 2.69%。分工况中，低频与高频正弦跟踪的 ISE 分别降低 7.08% 与 32.72%；阶跃、负载扰动、量测噪声、模型摄动四类工况的 ISE 分别高于基线 4.16%、4.61%、17.49%、4.51%。**量测噪声是已知性能边界，不能表述为全面占优。**

**航空发动机对象（二输入二输出）**：七类仿真场景综合 ISE 由 0.3668 降至 0.3143，降低约 14.3%。该结论限定在该固定工作点线性化模型、该测试集合与仿真比较之下，不代表真实发动机试验，也不代表全包线全面优于固定参数 PID。

**训练与选模**：BP 网络采用离线预训练，96 轮候选训练后按独立验证集选取第 95 轮权重；训练集、验证集与测试集严格隔离。

**控制器消融（发动机侧）**：依次移除稳态前馈、直接通道解耦、增益修正、相位超前四个模块，综合 ISE 分别上升 209%、244%、72%、7.4%；雅可比来源对比中，符号雅可比优于 RBF 估计与解析解。

## 边界声明

- 全部结果为仿真结果，无真实发动机试验、无硬件在环、无实物部署
- 发动机对象为固定工作点附近的线性化模型，测试阶段对象特性不随时间变化
- RBF 辨识器仅用于离线预训练阶段提供局部灵敏度（雅可比）信息，测试阶段由 BP 网络生成控制增益
